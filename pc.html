This page is the front door to the Windows environment. Point it at your running dockurr/windows container and it will load the desktop right here.

  1. Start the container: docker compose -f windows10.yml up -d (or run it in a Codespace).
  2. Note the desktop address — http://localhost:8006 locally, or the public https://…-8006.app.github.dev URL from the Codespaces Ports tab.
  3. Put it in .env as VM_DESKTOP_URL=… and restart npm start. ( Phones/other devices can’t reach localhost; use the Codespace URL or a tunnel for those.)
The machine URL is set, but the browser refused to embed it. That usually means the desktop sends X-Frame-Options / a restrictive frame-ancestors, or it isn’t publicly reachable. Use “Open in new tab” instead — the desktop still works, it just isn’t framed.
