XYVORA FOR DEVELOPERS

Developer API.

Add Xyvora text replies to your app. The public endpoint is free to call and needs no API key. Capacity and safety limits still apply.

Make a streaming request

POST /api/chat accepts JSON and returns server-sent events. Run this example in a terminal or call the endpoint from your server.

curl -N https://xyvora.net/api/chat \
  -H 'Content-Type: application/json' \
  -d '{"model":"xyvora","mode":"instant","messages":[{"role":"user","content":"Explain why leaves change color."}]}'

Request fields

        

          
messages
Required. Start with user, alternate assistant and user, and end with user. Up to 19 messages, 8,000 context characters and 6,000 characters on the last message. Attachment content shares the context budget.

          
mode
normal (default), instant, thinker, pro, or creative. Modes change context and generation settings; they are not different models.

          
attachment
Optional {name, text} reference excerpt. Text only; no file uploads or images on this endpoint.

          
Other options
model defaults to xyvora. timeZone accepts an IANA zone. Optional searchQuery can go to external search services. Optional memory is an array of short notes you send, not a lookup of an account.

        

      

      

        
Read the stream

        
    
          
  • Append choices[0].delta.content text in order. Some events carry sources metadata instead of text. Ignore SSE comment lines starting with :.
    • 
          
  • Only data: [DONE] means the reply completed. A JSON error event can follow an HTTP 200 when inference fails. Closing the stream requests cancellation.
    • 
          
  • Read X-Xyvora-Source to distinguish server, skill, clock, and preview responses. Preview responses are samples, not live inference.
    • 
        

      

      

        
Limits and integrations

        
Handle 429 using Retry-After and avoid parallel retries. Input limits, busy responses, and upstream search limits still apply. This is a public service without a throughput guarantee. Cross-site browser calls are not enabled; call from your backend.

        
In the workspace, approve public GitHub and npm reads, or connect supported providers where configured. Those plugins, hosted images, account memory, and background tasks are not part of the public text API. Xyvora does not proxy arbitrary URLs or run actions from a model reply.
