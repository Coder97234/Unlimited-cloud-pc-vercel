XYVORA POLICIES

Privacy Policy.

What Xyvora receives when you use chat, what stays on this device, and the privacy controls you can use.

Chat and files

Guest chat does not require an account. Guest chats, theme, and guest memory use local browser storage. If you sign in, saved chats, settings, and selected memory notes sync to your account instead. They are not an encrypted vault.

To generate a reply, the server can receive your current message, limited recent messages, extracted attachment text, enabled memory notes, and time zone. On-device tools can give some answers without a chat request. Temporary chat does not enter history. Temporary chat and This message only do not use saved memory, but can still send the current prompt for processing. These controls do not change hosting logs.

Vercel hosts the service and processes the request to serve and protect it. Operational logs can include network, timing, and error information. Temporary chats aren’t saved to the account database. Saved signed-in conversations can include extracted attachment text, not original uploaded files.

Accounts, memory, and tasks

If enabled and you sign in, Xyvora stores the provider and stable identity, account name, verified email when provided, and a session record. For legacy password accounts, Xyvora stores the verified email and a salted password hash. The configured email delivery service (Bird or Resend) processes the address and a time-limited verification or recovery email. Xyvora’s database stores a digest of the link token or code, not the raw value. When configured and selected, Supabase Auth instead handles sign-in and verification codes. App session cookies contain a random token, not provider credentials.

Accounts sync chat history, settings, and the notes you choose to save. Where projects are enabled, file extracts and instructions are stored with the project and matching excerpts can be included in replies. Original uploads are not retained in the library. Temporary or isolated messages do not use project data. Pause, edit, or remove notes under Memory. When available, background tasks store the prompt, result, status, and timestamps under that account. Results are available in the app for up to 30 days; remove tasks sooner from Background tasks. Expired database records are cleaned up periodically.

Sign out to end this browser’s session. Where available, use Manage sessions to revoke other sessions. Use Your account → Delete account to remove the account, sessions, saved chats, settings, project files/instructions, synced memory, and background tasks from Xyvora’s active database. This does not remove files you downloaded, guest browser data, or an old local copy. Hosting backups and operational logs may be retained separately.

Optional providers

  • When configured, web search and research send only the selected query to the workspace’s SearXNG instance, which may query its configured indexes. Automatic search can be turned off in Workspace settings → Replies. Don’t include private data in a query. Xyvora receives snippets, not full pages.
  • Identity sign-in exchanges information with the provider you choose: Google, GitHub, or Discord where configured. It does not grant access to external accounts beyond sign-in.
  • Helio 1 uses the bundled model. Where Helio 2–5 are enabled, the current prompt and included context (such as recent messages, notes, file extracts, and search evidence) go to the workspace’s inference server to run an installed model. This is not inference in the visitor’s browser. The Helio selector does not use paid model providers. An older signed-in API integration that explicitly opts into a hosted model can still send context to its configured provider.
  • Optional Gmail and Vercel connections require a verified session, provider consent and approval before each read. Results stay in the settings panel unless you attach and send them. Encrypted connection cookies expire within an hour. Disconnect in Xyvora or revoke the provider grant.
  • Read-aloud uses the selected installed device voice. It does not use your microphone or send the audio or reply to a speech service.
  • General workspace plugins and hosted image tools are paused. Image previews stay on your device. Older saved photo turns can contain the filename and conversation, not the image bytes.

External services have their own privacy notices. If you previously granted access to an external account, you can revoke that grant in the provider’s own account settings.

Optional measurement

With permission, active browser tabs send an activity signal for the public usage report. Xyvora stores a digest of a random browser identifier and day and last-active time. The measurement tables do not store IP addresses, account IDs, prompts, or pages visited. The server may use the connection IP temporarily to protect the endpoint from abuse.

Browser activity is eligible for cleanup after 90 days. Withdrawal removes identified activity from reports and deletes its daily rows, while briefly keeping a revocation marker to prevent older tabs from recording again. Use Cookie choices to opt out.

Your choices

Clear saved conversations in Workspace settings or export an open chat with its download button. If you use a shared device, clear this site’s history and sign out when done. For supervised classroom use, read For schools and don’t submit student records.

For general questions, use the public project issue tracker. Don’t post private account details, student information, or other personal data there.
